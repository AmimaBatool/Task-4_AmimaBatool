Title: General Knowledge Quiz Game

General Knowledge Quiz Game is a simple command-line quiz application developed using Python. The game contains 10 general knowledge multiple-choice questions. The user selects an answer from four options (A, B, C, or D), and the program immediately shows whether the answer is correct or wrong.

Features:
 1. Contains 10 general knowledge questions.
 2. Provides four multiple-choice options for each question.
 3. Accepts answers in A, B, C, or D format.
 4. Automatically converts the user's answer to uppercase.
 5. Checks each answer immediately.
 6. Displays "CORRECT!" for correct answers.
 7. Displays "WRONG!" and shows the correct answer for incorrect answers.
 8. Stores the user's guesses.
 9. Calculates the final score.
 10. Calculates the final percentage.
 11. Displays the complete quiz result.
 12. Simple command-line interface.

How to Run:
 1. Download the project file.
 2. Open the project file in your VS code or any other editor. Make sure that python is installed in your computer.
 3. Open the terminal in project folder.
 4. Run this command "python Quiz_General_Knowledge.py" and press enter. Or simply run and debug the project.
 5. Program will run.
 6. Enter the desired password length.
 7. The program will generate and display a random password.
